# Momentum Home-Screen Widget

One responsive native Android home-screen widget is included. Earlier separate widget concepts are not included.

Small: Momentum percentage and completion.
Medium: Momentum, up to three habit check-in buttons, Quick Expense and Mood.
Large: Momentum, up to four habit check-in buttons, Quick Expense, Scan Receipt, Mood, Mood + remark, and Next reminder.

Widget actions launch the existing app flow so the same local-first and Firestore-backed state remains the source of truth.
