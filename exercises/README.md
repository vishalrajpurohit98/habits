# Exercise demo photos

`<id>_0.webp` is the start position and `<id>_1.webp` the end position for the exercise with that id in `EX_LIB`
(for example `pushup_0.webp`, `pushup_1.webp`). When both exist, the guide page shows them in Correct form and in the
three steps; otherwise it shows the illustrated figure.

The photos here come from Free Exercise DB (https://github.com/yuhonas/free-exercise-db), released under the
Unlicense (public domain). `sources.json` maps each id to the source exercise name. To add your own, keep files around
480 px wide and only use media you have the rights to.
