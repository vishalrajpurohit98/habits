# Personal Tracker — Productivity Suite V2

## Added
- Weekly Pulse dashboard on Today with 7-day consistency, completed count, current streak, overdue count and due-today count.
- Daily Review with habit/task summary and persistent reflection fields.
- Smart local insights for strongest/weakest habit and overdue actionable backlog.
- Actionable aging indicators and an aging summary: overdue, due soon, 7d+ aging, average age.
- Material-style ripple feedback, spring motion, page navigation transitions and staggered content entrance animations.
- Reduced-motion support for accessibility.

## Preserved
- Existing habit scheduling, streaks, freezes, reminders and recovery.
- Existing tasks, subtasks, comments, recurrence, exports and habit-task linking.
- Existing calendar, statistics, mood, sleep, journal, money, AI, sync, backup/import and Android native wrapper.
- Existing production signing key (`android-wrapper/keystore.b64`) is retained.
