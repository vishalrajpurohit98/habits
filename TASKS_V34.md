# Personal Tracker V1.4.1 — Journal

- Added Journal as a first-class navigation tab.
- Journal is intentionally text-only: no photos, videos, audio attachments, documents, or Firebase Storage dependency.
- Added timeline and calendar views.
- Added daily prompts and reusable journal templates.
- Added journal streak, monthly entry count, and total entry count.
- Added On This Day memories.
- Added mood selection and today's tracker context.
- Added journal search and hashtag filtering.
- Added AI entry actions: improve writing, summarize, analyze/reflection, and plan tomorrow via the existing AI Chat.
- Added journal text word count.
- Journal data remains part of the existing local backup and Firestore record-level sync.
- Legacy journal media references are ignored by the new text-only journal model.
