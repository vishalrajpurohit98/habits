# Changes in this build

- Added per-tab Edit mode for Today, Mood, Money, Stats, AI Assistant, and Settings.
- Added per-tab persistent section ordering with Up/Down controls.
- Added per-section persistent collapse/expand state.
- Added weekly target field for habits (1-7 completions/week).
- Added weekly target progress display on habit cards.
- Added receipt scanning in Money > Add expense using Google Gemini vision when Gemini is selected/configured.
- Receipt scanning fills amount, merchant, date, category, payment method and note for review before saving.
